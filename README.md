# SimpleTab:
SimpleTab is a minimalistic custom new-tab.

## What I used to build this project:
- Html
- CSS
- JavaScript
- Vite
- Node.js
- NASA APOD API
- GitHub Pages

## Features:
- Custom new-tab homepage
- Web search bar using Google
- Science Facts section
- NASA Astronomy Picture of the Day (APOD)
- Supports NASA images and videos

Shortcut buttons for:
- YouTube
- Stardance
- LinkedIn
- Hack Club

Live clock displaying:
- Current time
- Current date

## NASA API:
SimpleTab uses NASA's Astronomy Picture of the Day API to display a daily science fact and image/video.

## Deployment:
The project is deployed using GitHub Pages.
You can use it on your browser using this link: https://endlessdude.github.io/SimpleTab/
